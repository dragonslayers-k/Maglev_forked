## What's new
- This fork's Android app is branded **Maglev+** and uses application ID `com.maglev.plus`, so it can install alongside upstream Maglev (`com.maglev`).
- Browser media detection now observes DOM media, fetch/XHR response metadata, Resource Timing, WebView requests and Service Worker requests.
- Korean localization improvements for browser and download flows.

## What's changed
- App version `0.34`, Android versionCode `34`.
- Updated launcher icon aliases, share intent helper package and updater's installed-package validation to the Maglev+ ID.
- Improved HLS/DASH candidate handling and duplicate-candidate enrichment.
- Added monthly upstream comparison workflow and Korean maintenance documentation.

## What's fixed
- Reduced false candidates from known HLS/DASH segment URLs in the found-media list.
- Added regression contract tests for the independent app identity and browser media detection changes.

## Notes
- Not a final release until CI, APK signature/package inspection and Galaxy device testing pass.
- No DRM or access-control bypass is included.
