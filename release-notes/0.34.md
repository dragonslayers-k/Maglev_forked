# 0.34

## Maglev+ fork build
- Renamed the Android app label to **Maglev+**.
- Changed Android application ID to `com.maglev.plus`, allowing installation alongside upstream Maglev (`com.maglev`).
- Updated launcher icon aliases, Android share-intent helper package, and in-app updater package verification to the fork identity.
- Bumped app version to `0.34` / Android versionCode `34`.

## Browser media detection and Korean UX
- Expanded media detection across DOM media elements, fetch/XHR metadata, Resource Timing, WebView request and Service Worker observation.
- Improved HLS/DASH candidate handling and duplicate candidate enrichment.
- Korean browser/download UI copy and tests.

## Notes
- This is not a final release until CI, signed APK verification, and Galaxy device testing pass.
- No DRM or access-control bypass is included.
