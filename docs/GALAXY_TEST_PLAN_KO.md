# Galaxy 실기기 검증 계획

## 목적

컴파일과 단위 테스트만으로는 실제 웹 플레이어·인증·쿠키·백그라운드 다운로드가 정상이라고 결론 내릴 수 없습니다. 아래 테스트는 Galaxy 기기에서 사용자가 실제 설치 APK로 수행해야 합니다.

현재 이 작업 환경에서 연결된 Galaxy 기기에 직접 설치하거나 브라우저 재생을 확인한 상태는 아닙니다. 결과는 기기에서 실행 후 기록해야 합니다.

## 준비

1. PR의 CI가 성공한 뒤 해당 CI에서 생성된 arm64 APK를 받습니다.
2. 앱을 설치하고 알림 권한 및 저장 위치 설정을 완료합니다.
3. 같은 콘텐츠를 브라우저에서 재생할 수 있는지 확인합니다.
4. 다운로드 권한이 있는 공개 테스트 영상 또는 본인이 관리하는 테스트 서버를 사용합니다.
5. 로그를 공유할 때 URL 토큰, Cookie, Authorization, Referer의 민감한 query parameter를 가립니다.

## 필수 테스트

| ID | 유형 | 절차 | 기대 결과 |
|---|---|---|---|
| G-01 | 직접 MP4 | 내부 브라우저에서 MP4 재생 | 감지 파일에 1개 후보, 파일 이름·크기 표시 후 다운로드 가능 |
| G-02 | 직접 WebM | WebM 재생 또는 미디어 링크 열기 | 동영상 후보로 표시 |
| G-03 | HLS 확장자 | VOD M3U8 페이지 재생 | HLS 표시, 화질 선택 창 열림 |
| G-04 | HLS AES-128 | 권한 있는 AES-128 clear-key VOD 재생 | 화질 선택 및 병합 성공 |
| G-05 | DASH 확장자 | 정적 MPD 페이지 재생 | DASH 표시, 화질 선택 창 열림 |
| G-06 | 확장자 없는 HLS | URL에 확장자가 없고 응답 MIME이 HLS인 테스트 리소스 재생 | MIME 기반으로 HLS 후보 감지 |
| G-07 | 확장자 없는 DASH | URL에 확장자가 없고 응답 MIME이 application/dash+xml인 테스트 리소스 재생 | MIME 기반으로 DASH 후보 감지 |
| G-08 | fetch | 페이지 JS가 GET fetch로 매니페스트를 요청 | 응답 URL/MIME을 관찰해 후보 생성 |
| G-09 | XHR | 페이지 JS가 GET XHR로 매니페스트를 요청 | 응답 URL/MIME을 관찰해 후보 생성 |
| G-10 | Service Worker | 자체 테스트 사이트에서 Service Worker가 미디어 GET 요청 | 현재 페이지 출처가 확인되는 요청만 후보 감지 |
| G-11 | 분리 오디오 | 영상·오디오 트랙이 분리된 VOD | 오디오 트랙 선택 후 결과 파일에 영상과 오디오 포함 |
| G-12 | 세그먼트 노이즈 | HLS/DASH 재생 중 감지 파일 목록 확인 | 매니페스트보다 세그먼트 항목이 더 많이 표시되지 않음 |
| G-13 | 재개 | 다운로드 중 일시정지 후 재개 | 이어받기 또는 명확한 재시도 안내 |
| G-14 | 로그인 세션 | 내부 브라우저에서 테스트 사이트 로그인 후 재생 | 가능한 경우 호스트별 CookieManager 쿠키가 다운로드에 전달됨 |
| G-15 | 외부 공유 | Chrome/Samsung Internet에서 페이지 주소 공유 | 앱으로 URL 전달. 외부 브라우저 로그인 쿠키가 자동 복사된다고 기대하지 않음 |
| G-16 | DRM | 합법적인 DRM 테스트 페이지 열기 | DRM/보호 상태 표시, 저장 우회 없음 |
| G-17 | Live | 종료 마커가 없는 HLS 또는 dynamic MPD | 저장 불가 사유를 표시 |
| G-18 | 세션 만료 | 다운로드 도중 토큰 만료 또는 접근 거부 유도 | 인증/HTTP 오류 표시, 임의로 권한을 우회하지 않음 |

## 기록 양식

각 시나리오에 대해 아래 항목을 기록합니다.

- 기기 모델 / Android 버전 / WebView 버전
- 앱 버전과 CI run URL
- 테스트 ID
- 브라우저 종류(내부 / Chrome / Samsung Internet)
- 재생 성공 여부
- 감지 여부와 표시 형식(HLS/DASH/MP4 등)
- 다운로드 시작·완료 여부
- 영상·오디오 싱크와 최종 파일 재생 여부
- 실패 시 화면 문구 및 민감정보를 제거한 로그

## 출시 승인 기준

- G-01부터 G-15까지 지원 대상으로 정의한 시나리오 통과
- G-16, G-17은 저장이 차단되고 올바른 사유가 표시
- G-18은 인증 오류를 구분하고 정상 재시도가 가능
- 기존 브라우저·다운로드·저장 위치 기능 회귀 없음
- PR CI의 typecheck, JS 테스트, Kotlin/Rust 빌드 및 계약 테스트 성공
- 실제 Galaxy 기기에서 설치·다운로드·재생 결과 기록 완료
